# leiautes — como abrir o chat

3 comandos, nada para colar:

| Comando | Quando usar |
|---------|------------|
| `/iniciar` | Sempre ao abrir o chat — te situa e cruza pendências |
| `/salvar` | No meio da sessão, quando a IA avisar que o chat está longo |
| `/fechar` | Só no final do dia — atualiza o bordo e salva no git |
